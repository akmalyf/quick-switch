# Changelog

## 1.0.0

Initial release.

- **Switch Project** popup (`⌘⌥P` / `Ctrl+Alt+P`): open windows first, then recent projects, with fuzzy search on name and path.
- Item buttons: open in new window, reveal in file explorer, remove from history.
- **Open Folder...** entry and header button to open a project that is not in the list yet.
- **Next / Previous Project Window** (``⌘⌥` `` / ``⌘⇧⌥` ``, `Ctrl+Alt+]` / `Ctrl+Alt+[`).
- Status bar item with the current project name, left of the git branch.
- Own project history shared by all windows, seeded once from VS Code's recent list.
- Settings: `quickSwitch.openIn`, `quickSwitch.showStatusBarItem`, `quickSwitch.historySize`.
- **Clear Project History** command.
